# Support

## Where to Ask

Use the repository's issue forms for public support:

- **Bug report** for reproducible problems in the boilerplate;
- **Feature request** for a reusable improvement;
- **Documentation** for unclear, missing, or incorrect guidance;
- **Question** for help understanding or using the baseline.

Search existing issues before opening a new one and include the relevant
environment, commands, and observed behavior.

## Security and Conduct

- Report vulnerabilities privately through [SECURITY.md](SECURITY.md).
- Report conduct concerns privately through
  [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).

Do not use a public issue for either type of report.

## Support Boundaries

This repository supports the reusable boilerplate itself. Projects created
from the template are independent and must be supported by their own owners.

Support is provided on a best-effort basis. There is no guaranteed response or
resolution time, and maintainers may close requests that are project-specific,
cannot be reproduced, or fall outside the boilerplate's scope.
